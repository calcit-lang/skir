# Upgrade Calcit 0.13.77 / 升级 Calcit 0.13.77

## English

- Aligned Calcit and `@calcit/procs` at exact 0.13.77, updated respo-router.calcit to 0.8.9, kept the prepared Skir version 0.0.22, and refreshed the immutable Yarn lock.
- Preserved the public Map options boundary by explicitly adapting the typed default options before merging.
- Migrated route extraction to explicit Option handling for both `get-in` and `nth`, restoring the JSON, HTML, and 404 HTTP behavior under 0.13.77; replaced the deprecated `tag-match` call with `match`.
- Added a reviewed no-growth quality baseline and hardened CI with immutable actions, strict Caps, exact toolchain verification, and real HTTP smoke tests.
- Published respo-router.calcit 0.8.9 still has one Nil/String equality warning in `match-pattern`, tracked by Respo/respo-router.calcit#33. A temporary source-only Option narrowing proves Skir check-only, JavaScript generation, and all three HTTP routes pass; no dependency workaround is committed.

## 中文

- 将 Calcit 与 `@calcit/procs` 精确对齐到 0.13.77，升级 respo-router.calcit 到 0.8.9，保持已准备的 Skir 版本 0.0.22，并刷新不可变 Yarn 锁文件。
- 在合并用户 Map 选项前显式适配带类型的默认选项，保持公开 Map 边界。
- 对 `get-in` 与 `nth` 的返回值显式处理 Option，恢复 0.13.77 下 JSON、HTML 与 404 HTTP 行为；同时把废弃的 `tag-match` 改为 `match`。
- 加入经审阅的无增长质量 baseline，并用不可变 Action、strict Caps、精确工具链校验和真实 HTTP smoke test 加固 CI。
- 已发布的 respo-router.calcit 0.8.9 在 `match-pattern` 仍有一条 Nil/String equality 告警，由 Respo/respo-router.calcit#33 跟踪。临时的纯源码 Option 收窄已证明 Skir check-only、JavaScript 生成及三条 HTTP route 全部通过；提交中不包含依赖 workaround。

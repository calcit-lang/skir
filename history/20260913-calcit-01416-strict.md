# skir 0.0.24 strict migration

- Upgrade Calcit and `@calcit/procs` from 0.13.77 to 0.14.16, and `respo-router.calcit` to 0.8.14.
- Set the default entry to the Node.js target and require zero dynamic method dispatch.
- Replace untyped Node.js member access with narrow external-object traits for HTTP requests, servers, buffers, headers, and promises. Incoming client responses and outgoing server responses use separate capabilities.
- Give all 44 project definitions structured schemas. Static debt changes from 15 untyped definitions and 28 unresolved occurrences to zero; seven definitions remain partially typed only at reviewed HTTP payload and JavaScript FFI boundaries.
- Replace the heterogeneous router result maps with `RoutePart`, `RouteRemainder`, and `MatchResult`, and add two behavior tests plus a runnable example.
- Make the unimplemented `post!`, `put!`, and `delete!` APIs explicitly return `Unit`, and assert generated router results through structured runtime accessors rather than serialized text.
- Keep 22 `unsafe-coerce` assertions in the per-definition quality baseline. They are the explicit host-boundary conversions that replace the previous implicit dynamic access, including restoring the hot-reload handler from its erased `DynFn` storage.

Validated with Calcit 0.14.16: strict checks for both configured entry functions, 38/38 public definitions, zero dynamic methods, zero deprecated calls, two router tests, router examples, README formatting/checking, JS code generation, immutable Yarn install, and toolchain verification.
